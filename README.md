# Chekushka Adventure — GitHub package

## Что лежит в проекте
- `game/chekushka_adventure.py` — игра на Tkinter, без pip-зависимостей.
- `version.json` — номер версии для проверки обновлений.
- `installer.ps1` — установка Python при необходимости и загрузка игры.
- `УСТАНОВИТЬ.bat` — запуск инсталлятора.
- `Запустить игру.bat` — локальный запуск из репозитория.

## Перед публикацией
1. Создай публичный GitHub-репозиторий.
2. Замени `YOUR_GITHUB_USERNAME` и `YOUR_REPO` в:
   - `installer.ps1`
   - `game/chekushka_adventure.py`
3. Загрузи ВСЕ файлы и папку `game` в корень репозитория, ветка `main`.
4. Запусти `УСТАНОВИТЬ.bat`.

## Как публиковать обновление
1. Измени игру в `game/chekushka_adventure.py`.
2. Увеличь `APP_VERSION` в начале файла, например `2.1.0` -> `2.1.1`.
3. Поставь такое же значение `version` в `version.json`.
4. Commit и push в `main`.
5. Игрок нажимает в главном меню «ПРОВЕРИТЬ ОБНОВЛЕНИЯ».

Обновлятор скачивает новую версию файла игры из `raw.githubusercontent.com`, затем заменяет его после закрытия текущего процесса и перезапускает игру. Сохранение `chekushka_save.json` не перезаписывается.

## Важно
- Репозиторий должен быть **публичным**, иначе загрузка без токена не сработает.
- Инсталлятор рассчитан на Windows 10/11 x64.
- Если Python отсутствует, сначала пробует `winget`, затем официальный установщик Python 3.13.7 с Tcl/Tk.
- Интернет нужен для установки и обновлений.
- Для реального установщика `.exe` можно позже собрать отдельный лаунчер; сейчас это установщик на PowerShell, запускаемый через BAT.
